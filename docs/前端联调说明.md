# Vue 2 页面联调（当前 2.6.0）

当前业务接口已逐页接入。完整接口/入口/调用链见 [42 项核查](接口接入核查.md)，操作流程和 PDF 恢复见 [使用说明](课程数据使用说明.md)。

| 页面 | 服务端数据/操作 |
|---|---|
| 登录/注册 | 邮箱验证码、注册、登录、恢复/退出、显式在线体验 |
| 总览 | 统计、课程、课程知识图 |
| 课程/详情 | 创建、归档、删除、资料上传/列表/详情/删除、PDF 原文件读取 |
| 课程题库 | 按课程查询、JSON 正式导入、手动单题新增；示例预览只在前端 |
| 课程图谱 | 整图读取/保存、便捷添加知识点和关系、可选任务关联 |
| 研习室 | 后端课程资料/PDF、课程问答、持久化问答历史 |
| 练习/错题 | 后端出题、判分、错题查询与加入复习任务 |
| 作答历史 | 账号历史分页、按课程筛选、重练入口 |
| 报告/计划 | 后端统计；复习任务增删改查 |
| 设置 | 最新资料、保存偏好、健康检查、账号记录导出、确认清空 |

写入顺序：提交表单 → API → 后端检查身份/参数并提交数据库 → 返回真实对象 → 更新 state。204 不解析 JSON。请求用账号作用域保护，切换账号不写入上个账号的迟到结果；本地体验与账号缓存隔离。

真实账号失败显示重试，不回退本地样例。旧版本未同步的本机课程需先同步。问答默认检索，不支持 OCR。示例模板不自动导入。导出不等于全库备份。


### 自定义计划清单

父任务 done 为只读聚合值。新建 custom 发送 `subtasks:[{title}]`；编辑发送完整有序 `[{id?,title}]`，已有项 done 由数据库保留。勾选调用 `PATCH /api/v1/tasks/{task_id}/subtasks/{subtask_id}` 的 `{done:boolean}` 并合并响应 TaskOut。全部完成才完成父任务；取消任何子项或添加新项恢复未完成。保存 409 应刷新并提示冲突，422 提示标题或清单不合法。收到 `notifications.changed` 后刷新计划/通知，详情见 复习提醒说明.md。
