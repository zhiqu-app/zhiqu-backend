# 课程题库、PDF 与接口接入使用说明（2.6.0）

## 使用顺序

1. 登录真实账号，在“我的课程”创建课程，打开课程详情。
2. 在该课程“导入资料”选择 PDF、TXT 或 Markdown。上传成功才加入账号资料列表。
3. 点击“配置题库”，下载 JSON 模板并填写。选择正式 JSON，预览题干及所有选项，再确认导入。上方可切换所属课程。
4. “预览前端示例（不保存）”只展示模板，确认按钮禁用；示例文件保留在前端 docs/question-bank.example.json。可用“手动新增题目”逐题录入。
5. “开始练习”读取该课程题库，由后端判分。练习页/设置中的“作答历史”可以按课程筛选、翻页和重练。
6. 课程详情的“快速添加知识点”“连接知识点”立即保存；“完整编辑”用于批量调整布局和关联复习任务。
7. 进入研习室后选择课程/资料，可预览后端 PDF、提交问题、恢复此课程之前的问答。

## PDF 在哪里、下次如何找

真实账号上传的 PDF 原始字节写入 MySQL materials 表的 content 字段（LONGBLOB），资料名、所属课程、类型、大小和解析结果同时保存。不是把浏览器 blob URL 存入数据库。

下次登录：我的课程 → 打开课程 → 课程资料 → 预览；或者研习室 → 选择课程 → 选择阅读资料。前端先查询 GET /materials?courseId=...，再以 Bearer 鉴权读取 GET /materials/{id} 与 GET /materials/{id}/file?inline=true，临时生成本次浏览器的 blob URL。

普通可解析 PDF 可以参与检索；只有扫描图像的 PDF 仍保存并可预览，但未提供 OCR。默认问答为课程资料检索；只有后端同时配置 AI_BASE_URL、AI_API_KEY、AI_MODEL 才调用外部模型。

本地演示/尚未同步的旧本机课程不属于真实账号上传流程，临时 PDF 不承诺跨会话保留。请使用已保存到账号的课程上传。

## 其他接口入口

- 登录：本地“体验示例课程”与“打开在线示例空间”分开；后者才创建服务端演示账号。
- 设置：读取最新 profile、检查健康状态、导出服务端学习记录、清空本人学习数据。
- 删除：课程卡片垃圾桶 → 确认，级联删除资料、题库、作答、图谱、问答与该课程错题生成的复习任务，手工复习任务保留。
- 清空：设置 → 清空账号数据 → 输入“清空” → 确认，保留登录账号和个人资料。
- 导出 JSON 不是完整备份，不含 PDF 原件、题库或星图。界面已明确说明。

详细 42 个接口与入口逐项见 接口接入核查.md。

## 启动与数据库

前端仍是 Vue 2 + Less + Axios；后端 FastAPI + SQLAlchemy + MySQL 8。本轮不修改 .env、不更换数据库、不新增迁移，Alembic head 仍为 0004。

```powershell
cd D:\zhiqu-backend\backend
.\.venv\Scripts\python.exe -m uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

已经运行 --reload 的原后端会随源码更新；没有 --reload 时重启原进程。同一个端口只运行一份。前端在 D:/zhiqu-app 按原来的 npm run dev 启动即可。账号数据库按 MySQL8配置说明.md 配置，API 地址沿用现有前端环境设置。
