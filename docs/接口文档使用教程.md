# 接口使用教程

前提：按 MYSQL8_SETUP.md 建好数据库并启动服务。实际调试地址为 http://127.0.0.1:8000/docs。本文接口都带 `/api/v1` 前缀。

## 1. 在 Swagger 调试

展开某个接口，点击 Try it out，填写参数或 JSON，再点击 Execute。页面会展示请求地址、状态码、真实返回内容和可复制的 curl 示例。

每个 Query/Path 参数都有 description；请求体下方 Schema 展示字段说明、必填、默认值、枚举和长度约束。响应也有具名模型，可以展开查看返回字段。

## 2. 注册，然后登录

先调用 `POST /api/v1/auth/email-code`，请求体为 `{"email":"student@example.com"}`，从真实邮箱读取 6 位验证码；然后调用 `POST /api/v1/auth/register`：

```json
{
  "email": "student@example.com",
  "password": "StudyDemo123!",
  "verificationCode": "替换为邮件中的6位数字",
  "name": "测试同学"
}
```

这是示例账号，只有你实际注册成功后才能登录；没有预置公共用户名密码。正常返回 201，邮箱重复返回 409。验证码是必填项，错误或过期返回 400；完整 QQ 配置见 EMAIL_REGISTRATION.md。默认不自动导入任何课程或成绩。

之后调用 `POST /api/v1/auth/login`：

```json
{
  "email": "student@example.com",
  "password": "StudyDemo123!"
}
```

成功返回如下结构，令牌内容和 ID 由本次请求实际生成：

```json
{
  "accessToken": "本次真实返回的令牌",
  "tokenType": "bearer",
  "expiresAt": "UTC到期时间",
  "user": {
    "id": "用户ID",
    "email": "student@example.com",
    "isGuest": false,
    "profile": {
      "name": "测试同学",
      "major": "",
      "grade": "其他",
      "email": "",
      "reducedMotion": false,
      "reminders": true
    }
  }
}
```

点 Swagger 右上角 Authorize，输入 **accessToken 本身**，再授权。普通前端请求则发送：

```http
Authorization: Bearer 本次真实返回的令牌
```

令牌是可撤销的随机会话，不是 JWT；不需要在前端解码。密码不要 trim，不要写到 localStorage。个人资料 email 是联系邮箱，不会修改登录账号。

调用 GET `/api/v1/auth/me` 确认身份。退出调用 POST `/api/v1/auth/logout`，返回 204 后清理前端令牌与账号内存状态。

## 3. 新建课程

调用 `POST /api/v1/courses`：

```json
{
  "name": "线性代数",
  "teacher": "王老师",
  "description": "矩阵与线性变换学习",
  "chapter": "第三章·特征值与特征向量",
  "lessons": 18,
  "cover": "linear"
}
```

返回的 `id` 就是后续所有 courseId。不要把课程名称当 ID，也不要把真实新建课程 ID 固定写为 linear。`linear` 只是体验样例中使用的标识。

GET `/api/v1/courses?limit=20&offset=0` 返回列表包装：

```js
// Vue 中读取课程数组
const result = await api.courses({ limit: 20, offset: 0 })
state.courses = result.items
```

GET `/api/v1/courses/{course_id}` 返回单个课程对象，用它的 name 显示知识星图的课程标题。

## 4. 给课程创建星图节点和连线

分别调用两次 `POST /api/v1/courses/{course_id}/knowledge/nodes`，路径里填第 3 步的真实课程 ID。

第一个节点：

```json
{"label":"矩阵","description":"矩阵的基本概念","x":100,"y":150}
```

第二个节点：

```json
{"label":"特征值","description":"满足 Av = λv 的特征值","x":385,"y":105}
```

记录各自返回的 id，调用 `POST /api/v1/courses/{course_id}/knowledge/edges`：

```json
{
  "source": "第一个节点实际返回的ID",
  "target": "第二个节点实际返回的ID"
}
```

source/target 是节点 ID，不是数组下标。节点必须属于同一账号、同一课程，不能自连，重复连接返回 409。

然后 GET `/api/v1/knowledge?courseId=真实课程ID`：

```json
{
  "courseId": "真实课程ID",
  "sample": false,
  "nodes": [
    {
      "id": "第一个节点ID",
      "label": "矩阵",
      "description": "矩阵的基本概念",
      "x": 100,
      "y": 150,
      "sample": false,
      "practiceCount": 0,
      "practiceRate": 0
    },
    {
      "id": "第二个节点ID",
      "label": "特征值",
      "description": "满足 Av = λv 的特征值",
      "x": 385,
      "y": 105,
      "sample": false,
      "practiceCount": 0,
      "practiceRate": 0
    }
  ],
  "links": [{"source":"第一个节点ID","target":"第二个节点ID"}],
  "edges": [[0,1]]
}
```

nodes 按坐标和 ID 稳定排序，所以实际 edges 必须使用本次响应的数组，不能与旧 nodes 混用。页面直接传：

```vue
<KnowledgeGraph
  :nodes="graph.nodes"
  :edges="graph.edges"
  :selected="selectedId"
  @select="selectedId = $event.id"
/>
```

当前动效组件会在收到图谱后绘线、再播放光点。后端只存节点与关系，不负责播放动画；读取图谱不会自动从讲义抽取知识点。

还附有 `examples/knowledge_walkthrough.py`，使用独立体验账号演示整个过程：

```powershell
.\.venv\Scripts\python.exe examples\knowledge_walkthrough.py --base-url http://127.0.0.1:8000
```

该脚本会新建一个体验账号、测试课程和两个节点，不修改已有账号资料，不输出令牌。测试数据会保存在本次体验空间中。

## 5. 上传课程资料

Swagger 选择 POST `/api/v1/courses/{course_id}/materials`，填课程 ID，再选择 file。使用文件选择框，不要把文件路径写进 JSON。

- TXT/MD：单个不超过 500 KB。
- PDF：单个不超过 20 MB、200 页；有文字层时解析，扫描件不 OCR。
- 当前账号原文件总量上限 100 MB。
- 原文件与正文存入 MySQL，刷新页面后仍能再次读取。

列表 GET `/materials` 不返回正文，详情 GET `/materials/{material_id}` 才返回 text。

PDF 预览需要认证，不能简单把受保护接口地址塞给 iframe。前端先带令牌获取 Blob，再创建地址：

```js
const blob = await api.materialBlob(materialId, true)
const previewUrl = URL.createObjectURL(blob)
// iframe 的 src 使用 previewUrl；关闭预览时 URL.revokeObjectURL(previewUrl)
```

## 6. 创建题库并提交作答

POST `/api/v1/courses/{course_id}/questions`：

```json
{
  "title": "对角矩阵 diag(2,3) 的特征值是什么？",
  "options": ["0 和 1", "2 和 3"],
  "answer": 1,
  "explanation": "对角矩阵的特征值就是主对角线元素。",
  "point": "特征值"
}
```

返回题目 id，但不返回 answer。创建权限仅用于维护自己的学习题库，不应把这个个人题库接口当作防作弊正式考试功能。

GET `/api/v1/questions?courseId=真实课程ID` 得到题目列表。POST `/api/v1/attempts` 提交：

```json
{
  "questionId": "实际题目ID",
  "choice": 1,
  "seconds": 25,
  "submissionId": "attempt_demo_0001"
}
```

返回 attempt/answer/explanation/source/point。前端不发送 correct、分数或作答日期；由后端判题和记录时间。一次提交网络重试沿用相同 submissionId 和请求内容；重新练习生成新的键。

GET `/mistakes` 查看错题；POST `/mistakes/{question_id}/plan` 将错题加入计划；GET `/reports/summary?range=7` 查看真实统计。只有实际作答才会产生记录，新账号没有成绩是正常情况。

## 7. 资料问答

POST `/api/v1/assistant/ask`：

```json
{"courseId":"实际课程ID","question":"对角矩阵的特征值怎么求？"}
```

默认 mode=retrieval，检索该账号该课程已解析资料。需要外部模型时，在后端 .env 同时填写 AI_BASE_URL、AI_API_KEY、AI_MODEL 并重启。地址填到 API 根，例如供应商的 `/v1`，程序再追加 `/chat/completions`。

返回完整 JSON，不是 SSE。sources 包含原文片段及 UTF-16 start/end，可在 JS 中用 text.slice(start,end) 定位。模型服务失败返回 502/504，不会伪装成生成成功。

## 8. 前端地址配置和错误处理

Vue 根目录 `.env.local`：

```dotenv
VITE_API_BASE_URL=http://127.0.0.1:8000/api/v1
```

复制 `examples/vue2-api.js` 为 Vue 的 `src/services/api.js`，按需合并现有文件。`examples/knowledge.js` 可对应到 Vue 的 `src/services/knowledge.js`。修改前端环境变量后重启 Vite，实际前端端口必须在后端 CORS_ORIGINS 中。

统一错误结构：

```json
{
  "error": {
    "code": "validation_error",
    "message": "参数校验失败",
    "details": [{"field":"body.password","message":"字段不符合约束"}]
  },
  "requestId": "本次请求标识"
}
```

401 清理登录状态并回登录页；404 表示资源不存在或不属于当前账号；409 提示冲突；422 展示字段问题；429 提示稍后重试；503 检查数据库。不要请求失败后用旧假数据冒充成功。
