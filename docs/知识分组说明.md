# 自定义大知识点与小知识点

## 使用

选择课程 → 配置课程星图 → 新增大知识点（例如“可靠传输”）→ 添加小知识点（例如“确认机制”“超时重传”）→ 可选关联复习任务、添加先后关系 → 保存课程星图。

大知识点由用户自行命名，不限定为教材章节。每个大知识点最多 6 个小知识点；保留当前课程总计 50 点、150 条关系的限制。展示页和学习总览按大知识点切换，只绘制当前组的小知识点。跨组依赖通过“前置知识／后续知识”切换目标组并选中知识点。

配置页可改名、调整大知识点顺序、移动小知识点及自动排布当前组。非空大知识点不能直接删除，先移动或删除其中的小知识点。移动不改小知识点 ID，因此任务关联与依赖保留。

画布随内容容器宽度调整，窄屏不再强制 640px；SVG 只投影显示坐标，不回写节点逻辑坐标。新增只为新节点选位，移动只为被移动节点计算目标组空位，删除／新建组不重排其他节点。只有主动点击“自动排布当前组”才重排。旧超额组保留所有内容与坐标，先移动多余节点后再保存。

前端已移除本地体验课程和业务假数据，业务列表不再从浏览器缓存恢复或与接口混合。登录后由后端读取；界面动效偏好和未提交草稿可暂存浏览器。登录页的在线示例空间仍由后端创建独立体验账号并提供数据，接口失败不会切换到本地体验。

旧节点暂时按每 6 点一组显示“待整理大知识点”，用户改名并保存后正式落库。读取不创建虚假知识点，也不会自动替用户判断知识分类。

## 数据库升级（MySQL 8.0）

在 `D:\zhiqu-backend\backend` 执行：

```powershell
.\.venv\Scripts\python.exe -m alembic upgrade head
.\.venv\Scripts\python.exe -m alembic current
```

版本应为 `0007`。本次新增 `knowledge_groups` 表，以及 `knowledge_nodes.group_id` 可空列和复合外键；原节点、连线、任务关联、资料不删除。连接仍使用原 `.env` 中的 MYSQL_HOST、MYSQL_PORT、MYSQL_DATABASE、MYSQL_USER、MYSQL_PASSWORD，无需新增配置项。

升级后启动／重启服务：

```powershell
.\.venv\Scripts\python.exe -m uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

## 接口

沿用 `GET/PUT /api/v1/courses/{course_id}/knowledge`，增加 `groups` 及节点的 `groupId`，Swagger 有字段 description。

```json
{
  "title": "网络知识图",
  "goal": "理解可靠传输",
  "revision": 0,
  "groups": [{"id": "reliable", "title": "可靠传输"}],
  "nodes": [
    {"id":"ack","groupId":"reliable","label":"确认机制","description":"理解 ACK 的作用","x":180,"y":150,"taskId":null},
    {"id":"retry","groupId":"reliable","label":"超时重传","description":"分析丢包后的恢复","x":580,"y":150,"taskId":null}
  ],
  "links": [{"source":"ack","target":"retry"}]
}
```

再次保存必须使用上次返回的 revision。组 ID 唯一、每点必须选择本次 groups 中的一个组、每组最多 6 点；错误返回 422，版本冲突返回 409，跨用户课程／任务返回 404。旧客户端省略 groups 时保留已有分组并兼容新未分组节点。

主要函数：`graph_view` 组装课程星图与任务状态；`save_course_graph` 锁定课程并事务保存；`group_rows` 按顺序读取当前课程的大知识点；`group_unassigned` 为旧节点生成只读临时组；`validate_membership` 验证归属及容量。前端 `normalizeGroups` 兼容旧响应、`groupSlice` 过滤当前组并重新映射连线下标、`relatedAcrossGroups` 提供跨组跳转、`layoutGroup` 为当前组自动排布。

## 消息动画

新未读消息到达后左右摆动 30 秒；期间再收到新消息会从头重新计时。打开面板、全部已读、关闭实时提醒或开启减少动态效果时提前停止，未读标记保留。
