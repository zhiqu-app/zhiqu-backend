# JSON 题库导入与练习使用说明

## 操作流程

1. 登录账号，在“我的课程”新建或打开已经保存到账号的课程。
2. 点击课程详情中的“配置题库”，或从练习页进入对应课程的“配置题库”。
3. 下载 JSON 模板，填写题干、选项、答案、解析与知识点。
4. 选择 JSON 文件，检查预览；点击“确认导入题库”才会写入后端。
5. 点击“开始练习”。真实账号题目从后端读取，提交后由后端判分并保存作答。
6. 答错的题可在错题本查看、重练、加入复习计划；报告与总览按后端记录统计。

每门课程独立拥有题库，不再默认展示数学题。空题库显示导入入口；请求失败显示重试，不回退到示例题。只有明确选择“本地演示”才保留示例题和本地判分。

## JSON 文件格式

目前支持项目现有的单选题，2～6 个选项。答案为从 0 开始的整数下标：第一项为 0，第二项为 1。不要填写 A/B 字符串。

```json
{
  "questions": [
    {
      "title": "TCP 提供哪一种服务？",
      "options": ["可靠的字节流传输", "只支持广播通信"],
      "answer": 0,
      "explanation": "TCP 提供面向连接的可靠字节流传输服务。",
      "point": "可靠传输",
      "source": null
    }
  ]
}
```

前端也接受直接以题目数组作为文件顶层，提交后端时统一转换为 `{"questions":[...]}`。支持 UTF-8 BOM。不要附加 userId、correct、courseId、id 等未定义字段。

| 字段 | 类型 | 规则 |
|---|---|---|
| title | 字符串 | 题干，1～500 字 |
| options | 字符串数组 | 2～6 个不同选项，每项 1～500 字 |
| answer | 整数 | 从 0 开始，小于选项数量 |
| explanation | 字符串 | 解析，1～5000 字 |
| point | 字符串 | 知识点，1～80 字，报告和星图统计按这个名称归并 |
| source | 字符串或 null，可省略 | 同一课程的真实资料 ID；不关联时省略或填 null |

文件不超过 100 KB，每批 1～200 题，每账号最多 1000 题。同一课程内，题干和选项相同即视为重复。查重时统一全半角英文字母、数字、ASCII 标点和全角空格，并忽略首尾空白和选项顺序。修改解析、答案、知识点或来源不会创建第二道题。相同题干搭配不同选项可以保存。

## 导入与作答规则

- 默认追加，不提供“替换整个题库”，避免删除已有作答、错题和统计。
- 手动新增发现重复时返回 HTTP 409。粘贴 JSON 和文件导入会跳过与课程已有题目或本批前面题目重复的项，并返回跳过数量。
- 任一题参数非法、来源资料不属于同一课程、超出配额，整批不写入，不出现一半成功。
- 后端根据 Bearer 令牌识别账号，检查课程/资料所有权；前端不能指定别人的 userId。
- 未提交时，题目查询不返回 answer/explanation。服务端成功保存作答后才返回本次答案快照和解析。
- 保存作答失败会保留选择，重试沿用相同 submissionId、选项和计时，避免重复记分。
- 练习草稿按账号和课程隔离，刷新可恢复已提交解析；重新作答会创建新记录，不覆盖历史。
- 本地演示与真实账号分开，真实账号不会因后端不可用而使用本地假题或假成绩。

## 后端接口

新增 `POST /api/v1/courses/{course_id}/questions/import`，请求体就是上方 questions 对象。使用已存在的本人课程 ID。

返回示例：

```json
{"courseId":"实际课程ID","imported":1,"skipped":0,"total":1}
```

`imported` 为新增数量，`skipped` 为重复跳过数量，`total` 为导入后课程总题数。400/422/409 等异常沿用统一 error/requestId 结构，字段约束和函数说明可在 `/docs` 查看。

本次复用现有 SQLAlchemy `Question`、`Attempt` 表，MySQL 配置无需更改，**不需要新的数据库迁移**，迁移仍为 `0004`。后端服务版本为 `2.6.0`。如果你的启动命令没有 `--reload`，修改后需要重启原后端进程；同一个 8000 端口只运行一份服务。

```powershell
cd D:\zhiqu-backend\backend
.\.venv\Scripts\python.exe -m uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

## 代码位置

- `app/question_import.py`：QuestionImport 参数模型、重复题比较规则、整批导入事务及配额。
- `src/utils/questionImport.js`：文件格式校验、题号错误提示与模板。
- `src/views/QuestionBank.vue`：配置页、模板下载、预览和确认导入。
- `src/services/questions.js`：题库、判分、错题、报告、总览请求。
- `src/views/Practice.vue`：按课程加载、幂等提交、保存成功后显示解析。
- `src/views/Mistakes.vue / Reports.vue / Overview.vue`：真实账号数据读取后端。
