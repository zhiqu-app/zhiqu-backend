## 数据边界

- 真实账号的题库、作答、错题、报告、课程资料和问答请求后端。失败显示错误和重试，不切换为假数据。
- 本地体验独立；在线示例空间只有用户明确点击才请求 auth/demo。前端示例 JSON 不自动上传。
- 星图完整编辑使用课程级 GET/PUT；课程详情的小量添加使用节点/连线 POST。便捷写入同步 revision、拒绝循环，旧整图保存返回 409。
- 账号导出读取服务端，不是全库备份：不包含 PDF 二进制、题库和星图。
- 清空需要输入“清空”；删除课程需要确认。前端只在后端成功后清理缓存。
- 本轮无新数据表/迁移；MySQL 8 保持 0004。PDF 原件原本已存在 Material.content（LONGBLOB），本轮补齐前端恢复读取。
