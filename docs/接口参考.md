# 独立接口参考

共 59 个 API 操作；由当前代码自动生成。

- 本地地址：`http://127.0.0.1:8000`，接口前缀 `/api/v1`。
- 调试入口：`http://127.0.0.1:8000/docs`；打开 Authorize 输入 accessToken 本身。
- 普通请求头：`Authorization: Bearer <accessToken>`。注册、登录、体验入口和健康检查无需登录。
- 除文件上传使用 multipart/form-data，其余写入使用 JSON。204 无正文。
- 正式账号默认空数据；数据需要先通过创建接口保存，不能直接套用示例资源 ID。
- PATCH：只发送要修改的字段，不能传 null 或空对象。
- 列表返回 items/total/limit/offset，前端应取 result.items，而不是整个响应当数组。
- 时间：返回 UTC ISO 8601；报告按天统计使用 Asia/Shanghai。
